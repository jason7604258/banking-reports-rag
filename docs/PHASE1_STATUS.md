## 環境與目前需求

實際檢查：MacBook Pro、Apple M2、8GB 記憶體；首次檢查時約 22GiB 可用磁碟空間。一般終端機 Python 是 3.11.2，Git 可用。Docker、Ollama 和 uv 未在 PATH 或已檢查的常見位置找到，不將此視為已完成全面安裝盤點。

第一階段只需要 Python、Git、網路及 pypdf。模型、向量庫、Docker 會在後續階段引入。8GB 記憶體下要先測試小模型與依序載入的方式，不能照搬較高記憶體機器同時執行所有服務的設定。

完成的虛擬環境與套件版本可查 `docs/environment_check.json`。目前套件只固定 `pypdf==6.10.0`，避免一開始安裝整套模型工具。

## 找到的資料問題

1. **PDF 與紙面頁碼不同。** 2025 PDF 的內建頁面標籤也不能當作紙面頁碼；已核對的紙面標籤保存在證據記錄，一般頁面仍保持未驗證。
2. **多欄與斷字。** 文字存在不等於段落順序正確；下一階段要處理跨行斷字、頁首頁尾與欄位順序。
3. **隱藏／重複圖表文字。** 2025 PDF 第 54 頁的直接抽取會重複帶出圖表標籤，也有版面上不可見的製作文字；目前只作原始抽取，不直接當最終 RAG 段落。
4. **章節標題不等於財務或地理範圍。** 同一頁及同一封信可同時有 CCB、ICB 與 UK 內容，必須按證據段落標記。
5. **近似數字與指標名稱。** 兩年數位客戶相關文字的措辭不同，先保留原定義，不用四捨五入數字算精確增長率。
6. **年報年度不等於現在。** 固定語料不能提供截至 2026-10-24 的即時客戶數。

## 你接下來可以做的事

1. 開啟 `evaluation/dev_questions.json`，先讀題目及 `expected_answer_points`，理解助手要回答什麼。
2. 對照上表的 PDF 頁面，閱讀其中兩至三頁，確認你對 CCB、ICB、集團／UK 範圍的理解。
3. 在 10 題中選出你最想展示的三題；這不影響已完成的來源準備。

沒有必要先讀完整 736 頁或先學會微調模型。下一個工作包是第二階段的乾淨抽取、章節切段和可追溯的 metadata，之後才建立向量搜尋。

## 重跑檢查

```bash
cd banking-reports-rag
source .venv/bin/activate
python scripts/prepare_sources.py
python scripts/verify_phase1.py
```

`prepare_sources.py` 在不帶 `--download` 時只核對本機來源，缺少檔案便停止。已經核對的來源若指紋不同，不會默默更新清單。
